① 虚拟列表（10,000 条教育经历）

仅渲染可视窗口（约 11 行），滚动时增量更新；删除按钮通过容器上的事件委托统一处理。

② 图片懒加载（IntersectionObserver）

可视区外图片不发请求，进入视口才填充 src；加载后淡入（opacity 合成层动画）。

④ 缓存（Map 内存缓存 + localStorage 持久化，TTL 5 分钟）

“匹配度估算”为昂贵计算，相同入参直接命中缓存，避免重复计算与重复渲染。

⑤ 输入防抖 / 节流

职责描述输入：防抖 300ms 自动保存草稿、防抖 统计字数（避免每次按键重排）；滚动位置用 节流 1s 写入缓存。

⑥ CSS 减少重排重绘

本页已应用的实践：
  • 动画仅用 transform / opacity，进入合成层，不触发 reflow/repaint 重计算
  • 屏外区块 content-visibility: auto + contain-intrinsic-size 跳过离屏渲染
  • 虚拟行定位用 transform: translateY 而非 top；列表容器 will-change: scroll-position
  • 读写分离：滚动处理中先批量读取 scrollTop，再一次性更新 DOM
  • 避免布局抖动（layout thrash）：不在循环里穿插 get 与 set
